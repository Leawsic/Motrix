# Motrix 2.0.0-beta.34

[English](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.34/docs/release-notes/2.0.0-beta.34.md) | 简体中文

Motrix 2.0.0-beta.34 改进了下载整理功能，支持可配置的 IDM 风格文件类型分类，
同时保留原有的默认下载行为。

## 主要改进

- **设置 → 常规 → 按文件类型整理下载**：开启后，HTTP 和直接下载会根据文件类型，
  保存到所选下载目录下可自定义的文档、压缩包、音乐、程序、视频或其他文件夹中。
- 分类文件夹名称会校验为安全的单级文件夹名称。引擎目录、任务记录、最终路径以及
  文件名冲突检查会统一使用分类后的实际目录。
- 未开启新设置时，现有下载仍保持保存到默认目录的行为。

## 测试前须知

这是预发布软件。安装前请备份现有 Motrix 应用数据和下载文件。Motrix v1 数据的
迁移路径尚未经过验证，请勿让本 beta 使用您唯一的一份 v1 数据。

Windows 安装包未签名，可能触发 Windows SmartScreen 警告。发布后请仅从官方
GitHub 预发布版下载。

Beta Server 镜像以不可变版本标签发布：
`docker.io/motrixapp/motrix-server:2.0.0-beta.34` 和
`ghcr.io/agalwood/motrix-server:2.0.0-beta.34`。详见
[Docker Server 部署指南](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.34/docs/docker-server.zh-CN.md)。

受保护的 beta 标签还会将经过验证的 `amd64` 和 `arm64` Snap 构建发布到
`latest/edge` 渠道。
