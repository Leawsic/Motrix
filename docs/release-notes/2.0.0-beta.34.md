# Motrix 2.0.0-beta.34

English | [简体中文](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.34/docs/release-notes/2.0.0-beta.34.zh-CN.md)

Motrix 2.0.0-beta.34 improves download organization with configurable IDM-style
file-type folders while preserving the existing default download behavior.

## Highlights

- **Settings → General → Organize downloads by file type** can place HTTP and
  direct downloads under configurable Documents, Compressed, Music, Programs,
  Video, or General subfolders below the selected save directory.
- Category folder names are validated as safe single-level names. The engine
  directory, task record, final path, and filename collision checks use the same
  categorized destination.
- Existing downloads remain in the default folder unless the new setting is
  enabled.

## Before testing

This is prerelease software. Back up existing Motrix application data and
downloads before installing it. Migration from Motrix v1 data has not yet been
validated, so do not use your only copy of v1 data with this beta.

Windows packages are unsigned and may trigger a Windows SmartScreen warning.
Download them only from the official GitHub prerelease after publication.

The beta Server image is published as an immutable version tag:
`docker.io/motrixapp/motrix-server:2.0.0-beta.34` and
`ghcr.io/agalwood/motrix-server:2.0.0-beta.34`. See the
[Docker Server deployment guide](https://github.com/agalwood/Motrix/blob/v2.0.0-beta.34/docs/docker-server.md).
